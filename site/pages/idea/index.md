Pattern Dump takes the view that a design system is only as good as its documentation. Documentation that can't drift is rendered from the component itself, every time it is shown.

[What it does](/idea/features/) lists each thing Pattern Dump does, one line each.

[From Pattern Lab to Pattern Dump](/idea/history/) tells where it comes from, in Stefan Bauer's own words.
